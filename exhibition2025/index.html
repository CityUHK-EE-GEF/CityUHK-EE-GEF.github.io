Project ID : P15

P15
Trust Radar: Confidence Radar for LLM
Student Names:
Zhang Jingkun; SHUM Ming Kuen Marco; DONG Jego
Video Demo
GitHub
A transparency layer between an LLM and the user that shows how confident the AI really is. For every response, Trust Radar identifies factual claims, measures token-level confidence and cross-run consistency, assigns a risk score (PASS / VERIFY / ABSTAIN), and fact-checks uncertain answers against Wikipedia — visualized on a Streamlit dashboard with a token heatmap.
